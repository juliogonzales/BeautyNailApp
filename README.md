# BeautyNailapp

Plataforma SaaS multi-tenant para profissionais da beleza. Regras do projeto: [`CLAUDE.md`](CLAUDE.md). Estado atual: [`PROJECT_STATUS.md`](PROJECT_STATUS.md).

- App: Next.js (Fase 1, em andamento).
